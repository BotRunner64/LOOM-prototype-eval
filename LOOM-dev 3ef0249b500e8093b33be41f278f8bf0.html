理想投递的会议：CVPR 2026.11.11-17 / RSS 2026.12.05

工程问题：如何通过多任务、多本体、多场景的 co-train，使统一策略在部署到新 domain 时，仅凭少量参考 context 即可适配，而无需重新训练或微调。

科学问题：跨 domain 的 co-train 能否使策略学会从 context 中提取适配信息，并将这种能力泛化到训练未见的 domain？对于原本需要使用目标 domain 数据进行参数学习的适配过程，context 条件推断能够在多大程度上替代它？

Domain 定义：由机器人本体、控制方式、相机配置和场景条件等因素确定的部署条件。实验中明确哪些因素发生变化、哪些保持固定；任务目标及其组合的泛化单独报告。

关于各种context作为condition的模式

核心思路：训练时，除了当前这一帧，再额外给模型看些「参考轨迹」或「参考画面」作为 context，让它照着例子适应当前的机器人、任务或阶段。下面列出所有可选的 context 类型。

与主问题的关系：本体校准、末端变化及仿真到真机迁移直接用于研究 domain 适配；任务示教、视觉提示、历史记忆和失败轨迹还涉及目标指定、状态补全等作用，将分别评估，避免把不同来源的 context 收益混为一谈。

首轮实验范围：优先验证模式 1（本体校准）和模式 9（更换末端），尽量隔离待适配的 domain 因素；其余模式作为统一策略的扩展能力。

每条模式的通用格式：模式文本描述（标明这是哪类 context） + 该模式可提供的输入。输入项标注 (选) 表示可以不给。

组合规则

  • 每种模式本身可选，模式内的输入项也可选（标 (选) 的）
  • 多种模式可以同时输入、叠加使用
  • 什么都不给 就等于退化成当前主流的单帧 VLA：只有当前时刻视觉 + 机器人状态观测 + 指令

上面这一整类「靠给示例来适应」的能力，就是原文说的 in-context adapt。

研究动机与核心假设

研究动机：当训练充分覆盖某个固定 domain 时，策略可能已将该 domain 的规律吸收到参数中，因此额外 context 的适配收益可能有限。context 的关键价值，可能在于提供训练未见的部署条件信息，减少策略对目标 domain 参数学习的依赖。

核心假设：跨 domain 的 co-train 不仅能够提高策略的直接泛化能力，还可能使其学会利用少量参考 context，在参数冻结的情况下适配未见 domain。

需要检验的预测：在训练充分覆盖的 domain 上，context 的额外适配收益可能较小；在未见 domain 上，相关 context 可能带来更明显的收益。该预测不预设收益随 domain 差异单调增加，也不排除 context 在已见 domain 中通过目标指定或状态补全发挥作用。

本研究将检验这种适配能力何时出现、依赖哪些训练分布，以及能够替代多少目标 domain 上的参数学习。

验证方案

重点验证三个问题：context 在已见和未见 domain 上分别有什么适配价值，co-train 是否提高利用 context 适配新 domain 的能力，以及 context 能在多大程度上减少目标 domain 的参数学习需求。

统一评测设置

基础训练时留出指定条件；实验一、二测试时冻结参数，提供少量独立参考，再在不同初始布局下执行任务。参考与测试轨迹来自不同 episode，均不进入基础训练。实验三的 context 组与微调组使用同一批指定的目标 domain 适配数据，但仅微调组用其更新参数；测试 episode 始终留出。

比较时保持观测和机器人状态的输入配置、任务指令及测试初始状态一致；闭环执行后的观测和状态随各策略动作自然演化。模型训练时覆盖有、无 context 两种输入；仅通过示例指定任务的评测单独报告。优先固定任务目标、改变 domain 因素，以区分 domain 适配与任务推断。

各组分别报告以下测试结果：

测试组训练覆盖或留出方式
已见 domaindomain 条件已被训练充分覆盖，参考与测试均使用独立 episode
未见 domain指定本体、末端、控制方式、相机配置或场景条件被留出；分别报告各因素，不将其全部混为一组

实验一：context 在已见和未见 domain 上分别有什么适配价值？

固定广泛 co-train 得到的同一个模型，在相同测试初始状态下比较：

  • 无 context：当前观测、机器人状态和任务指令。
  • 相关 context：相同输入，加上与待适配 domain 相关的少量参考。
  • 无关 context：相同输入，加上不提供目标 domain 适配信息的参考；尽量匹配参考数量、长度、模态和任务内容，明确被替换的 domain 因素。

指标：各设置的闭环成功率、相关 context 相对无 context 的成功率提升，以及相关 context 相对无关 context 的提升；报告重复试验的置信区间。

结果解释：未见 domain 上相关 context 相比无 context 和无关 context 均带来稳定提升，支持 context 提供了有用的适配信息。若已见 domain 上收益较小、未见 domain 上收益较大，则进一步支持研究动机；解释差异时需考虑成功率的天花板效应，不能仅凭已见 domain 收益小就认定模型未使用 context。

实验二：co-train 是否提高利用 context 适配新 domain 的能力？

改变训练 domain 的多样性，在对两组模型均留出的同一目标 domain 测试集上比较：

训练分布无 context有相关 context
较窄的 domain 分布AB
广泛的跨 domain co-trainCD

A–D 表示闭环成功率。两组模型都训练使用 context 的能力，尽量匹配模型容量、总训练样本量与计算预算，使用相同参考和测试初始状态。优先固定任务覆盖范围，改变 domain 多样性；若同时扩大任务分布，则单独报告，避免混淆两者的作用。

  • D 高于 C：广泛 co-train 后，context 仍提供额外泛化收益。
  • D 高于 B：广泛 co-train 提高了有参考条件下的泛化表现，但单独这一比较不足以说明模型更善于利用 context。
  • C 与 A：衡量 co-train 带来的直接泛化收益。
  • D − C 与 B − A：比较两种训练分布下 context 的增量收益，并结合两组各自的无关 context 对照、置信区间及成功率的天花板效应判断。

D − C 大于 B − A 可作为 co-train 增强 context 利用能力的证据之一，但不是所有测试条件下的必要结果：co-train 也可能增强无参考能力，降低部分条件对 context 的需求。

实验三：context 能在多大程度上替代目标 domain 的参数学习？

从同一个广泛 co-train 的基础模型出发，在未见 domain 上比较：

  • 直接泛化：冻结参数，无 context。
  • Context 适配：冻结参数，提供少量目标 domain 参考。
  • 参数适配：使用目标 domain 数据微调，测试时不提供参考 context。

主要对照使用同一批目标 domain 示范数据：context 组将其作为参考，微调组将其用于参数更新。对多个示范数量分别评测；若 context 长度限制导致两组实际可用信息不同，明确报告，避免将其视为严格的数据等量比较。

指标：不同示范数量下的闭环成功率、context 适配与参数适配的性能差距，以及达到预设成功率所需的目标 domain 示范量。同时报告微调计算开销、测试时参考长度和推理开销。

可增加使用更多目标 domain 数据训练或微调的模型作为经验性能参照，并明确其额外数据和计算预算。

支持假设的结果：冻结模型加少量 context 能在未见 domain 上获得稳定适配收益，并在一定数据预算内接近参数适配的表现。报告其成立范围和失败条件，不预设 context 能完全替代目标 domain 的参数学习。

Prototype 实验

目标：验证策略能否利用短参考轨迹，在参数冻结时适配未见相机视角；进一步检验跨 domain co-train 的作用。

设置

  • 环境与任务：Isaac Sim 中固定机器人、夹爪和桌面场景，抓取方块并放到固定区域；随机化方块初始位置，只改变一个外部相机的位置与朝向。
  • Context：同一视角下，末端沿两个不共线方向移动的短校准轨迹，包含图像、state 和动作。校准与任务执行来自不同 episode，不提供任务解法。
  • 模型：小型条件行为克隆策略，输入当前图像、state、固定指令及可选 context，输出末端 relative pose 和夹爪动作；训练覆盖有、无 context。相机位姿和物体真实坐标不直接输入策略。

第一阶段 Context 是否有效

训练使用若干视角，留出其他视角。测试时冻结同一模型，在相同初始布局下比较：

  • 无 context
  • 正确 context：当前测试视角的独立校准轨迹。
  • 错误 context：其他视角的校准轨迹，匹配运动内容、长度和模态。

判断标准：未见视角上，正确 context 的闭环成功率稳定高于另外两组；重复评测并报告置信区间。留出视角的任务与校准轨迹均不进入基础训练。

第二阶段 Co-train 是否增强适配

比较少量视角与较多视角训练的模型，匹配总样本量、模型容量和计算预算。在共同留出的视角上，各自比较有、无 context，并保留错误 context 对照。

判断标准：比较两种训练分布下 context 带来的成功率增量，结合置信区间和天花板效应解释；较多视角模型的有参考成功率更高，单独不足以说明其更善于利用 context。

第一阶段出现可重复收益后开展第二阶段，再迁移到自有真机平台。
