# 实验协议与实现契约

## 数据设计

配置为 `configs/prototype.json`，固定种子 20261011。8 个基础训练视角（v00–v07），其中 narrow 仅使用 v01、v05；4 个共同留出的相机视角（v08–v11）。相机内参、分辨率 128×128、机器人、任务目标、光照和场景保持固定，变化仅是相机外参和方块初始位置。v11 超出训练方位角范围，其余三个是训练方位角之间的留出视角，分别报告。

| 内容 | 每个基础训练视角 | 每个留出视角 |
| --- | ---: | ---: |
| 训练任务 | 96 | 0 |
| 验证任务 | 16 | 0 |
| 测试任务 | 32 | 32 |
| 训练校准 context | 8 | 0 |
| 验证校准 context | 4 | 0 |
| 测试校准 context | 8 | 8 |

合计 1,280 条任务轨迹、192 条校准轨迹，共 1,472 个单相机 episode 文件。一个物理 episode 在多个相机下同时记录，以精确匹配各视角的机器人运动和物体布局；合计 164 个不同物理 episode。跨视角复制属于同一 episode，因此所有复制必须保留在同一 split。训练、验证和测试初始布局来自互不重叠的随机种子区间；校准种子额外偏移 500,000，与任务布局及动作均独立。

校准 episode 与任务 episode 分开重置。末端位于物体上方，夹爪打开，依次沿 X、回原点、沿 Y、回原点移动；不触碰方块、不执行任务解法。模型均匀读取 16 个时刻的 RGB、state 与单步 action；16 个时刻覆盖整段约 4 秒校准，不把其误称为连续 16 帧。通过两个独立方向的位置变化奇异值检查验证内容。

Heldout 的任务与校准只保存在 `test` split，基础训练和验证的 Dataset 会拒绝选择这些视角。验证参考来自独立 `val` 校准，评测参考来自独立 `test` 校准。当前任务真实位置、相机位姿、episode/view ID、成功标签、专家阶段和测试布局均不进入策略。机器人末端位姿及夹爪 state 是允许的可测输入。

## 物理与数据格式

使用 Isaac Sim 6 / Isaac Lab 3 的原生 PhysX、Panda articulation、相机及 DLS 逆运动学，物理频率 120 Hz，控制和采集频率 30 Hz。机器人手部使用 `panda_hand`，所有 quaternion 在 Isaac Lab 3 内是 xyzw；存储旋转用矩阵前两列的 rotation6D。

每个 HDF5 文件包含：

- `rgb`: uint8，[T+1,128,128,3]，无损 LZF 压缩。
- `state`: float32，[T+1,10]，`[x,y,z,R00,R10,R20,R01,R11,R21,gripper]`；位置为机器人世界坐标（本体固定），夹爪开度为两指间距/0.08 m，截断到 [0,1]。
- `action`: float32，[T,10]，相邻观测 `inv(T_t) @ T_(t+1)` 的末端相对位姿，以及下一时刻的绝对夹爪开度。
- `timestamp_ns`: int64，逐项取整的有理数 30 Hz 时钟。

训练 chunk 的第 k 个目标是 t+(k+1)/30，**所有 delta 都相对同一个当前时刻**，不是依次累乘；末尾不足 16 步时只监督有效前缀。推理先相对同一锚点恢复 chunk 的所有绝对目标，再依次执行前 4 步后重新观测。

专家采用物理夹持和反馈到位等待，不固定/附着方块、不重置物体以伪造成功。轨迹必须同时满足物体曾升到桌面以上 0.10 m，以及最后在固定目标的 ±0.05 m XY 区间内、Z 处于 [0.012,0.045] m、线速度小于 0.08 m/s。专家失败直接停下，不替换为静态示意图或非物理数据。

`manifest.jsonl` 记录文件 SHA256、split、相机、物理 episode ID 和仅供验收使用的初末物体位置。`audit` 检查完整数量、所有文件哈希、RGB 时序、动作坐标、时钟、物理成功、校准双方向以及同一 episode 的跨视角状态一致性。

## 策略与参考项目的对应

参考 `/home/jw/projects/my_projects/bq_native_policy`，提交 `660a8fb79d824bbbb7d1d87bc96a00342599561f`。沿用其同锚点 relative pose、rotation6D 前两列、未来绝对夹爪、30 Hz/16 步 action chunk、固定可逆归一化和独立 Transformer flow-matching head。几何实现从参考项目迁入并缩为单臂 10 维。

Prototype 文档要求“小型条件行为克隆”，因此视觉骨干是从头训练的小 CNN，而非参考项目的 Qwen3.5-2B。CNN 保留 4×4 空间 token 和可学习空间位置；context 逐帧加入 state/action、时序位置与校准类型 embedding，当前图像/state、context 及固定任务 embedding 作为 cross-attention memory。固定指令只有一条，其文本在配置中记录，模型用单一学习 embedding 表示；不声称有开放词汇语言能力。

Flow matching：`a_t=(1-t)*a_data+t*noise`，速度目标 `noise-a_data`；从 t=1 高斯噪声向 t=0 反向 Euler 积分 10 步。平移除以 0.1 m，rotation6D 减单位旋转，夹爪由 [0,1] 映射到 [-1,1]。输出旋转投影为合法 SO(3)，夹爪裁剪。模型每个训练样本以 50% 概率完整屏蔽 context token，保证有/无参考都受到监督；错误 context 仅用于对照评测，避免为错误适配信息训练目标域动作。

AdamW，lr=3e-4，weight_decay=0.01，1,000 步 warmup + cosine 衰减，20,000 次更新，每步 32 样本，梯度范数限幅 1，默认 BF16。两组模型容量、batch、总更新次数和视觉/context token 预算相同，共 640,000 次样本呈现；视角数从 2 增为 8，任务覆盖和每个物理布局库相同。固定种子/step 生成 batch 和参考选择，checkpoint 保存模型、优化器、scheduler、数据标识、全部 RNG 和更新进度，可恢复。

## 评测与判断

第一阶段固定 broad 模型，评测 8 个已见、4 个未见视角。每个视角 32 个独立测试布局，每个布局 3 次噪声/参考重复，三组共用初始机器人状态、物体布局和推理噪声种子：无 context、正确 context、其他视角的错误 context。正确和错误参考来自**同一个独立物理校准 episode**的两个相机记录，所以运动、长度和模态完全匹配。

参数冻结，模型只根据当前图像、可测 robot state、固定指令和可选参考决定动作。物体真值只用于验收成功，最多执行 600 控制步；满足落区条件连续 20 步且曾物理抬起才算成功。共同的末端工作区限幅为 XYZ [0.25,-0.4,0.105] 至 [0.75,0.4,0.55] m，执行步数限幅不改变组间设置。

报告每个视角与 seen/heldout 分组的成功率；配对比较 correct−none、correct−wrong。第一阶段出现可重复收益后，再训练 narrow；在共同四个留出视角上比较 broad 的增量与 narrow 的增量（差分的差分），同时保留错误参考对照。`statistics` 先在同一训练种子和布局内平均相机及重复结果，再同时对训练种子、布局作 5,000 次配对 bootstrap，报告 95% CI。另给每视角描述性 Wilson CI；解释时保留天花板效应，不将 broad 的绝对成功率较高当作 context 利用能力增强的充分证据。

本次只准备数据和实现，不进行任何优化器更新。未训练模型的 dry-run、专家成功率和后续冻结策略的任务成功率是三件不同的事；前两者不能证明 context 适配假设。
